# 沙画色板：三大类 × 每套 5–6 色

> 所有沙画风格的色板都从这里选。不要自己调色，除非你把新的一套色板登记进这个文件并通过了至少一次成片验证。
> 色板写进镜头表和 spec 的 `palette_name`。全片所有片段的 palette_name 必须是同一个。

## 用法

### 代码里（scenes/*.js，推荐直接用 palette 函数）

```js
// 经典暖沙·标准
const C = SAND.palette('classic_warm_standard');
// 展开后：C.lightTable、C.sandColors[0..4]、C.grainColor、C.thinAlpha、C.thickAlpha

// 多彩彩沙·庆典
const C = SAND.palette('colorful_celebration');
// 展开后：C.lightTable、C.layers[] 每层 {color, pct, layerIdx}、C.grainColor

// 夜间荧光·星河
const C = SAND.palette('glow_galaxy');
// 展开后：C.lightTable、C.sandBase、C.glowColors[] 每色 {color, intensity, pct}、C.glowBlur、C.bloomStrength
```

### JSON spec 里（参数化片段）

```json
{
  "theme": "classic_warm",
  "palette_name": "暖沙标准-5色"
}
```

`theme` 必须三选一：`classic_warm` / `colorful` / `glow_night`。palette_name 从上面对应类的表选。不一致会被 lint 标红灯。

## 色板的硬约束

1. **经典暖沙不允许出现蓝色紫色青色色相**。HSL 的 H 值：所有沙色 H 在 20°（红棕）到 50°（金黄）区间内。光台色 H 35°–45°。
2. **多彩彩沙暖色占比必须 ≥70%**（各层 pct 加起来：红、橙、黄的 pct 总和 ÷ 所有 pct ≥ 0.7）。蓝、绿、紫只是点缀。
3. **夜间荧光的光台必须是蓝紫**。这是唯一被允许的蓝紫光台。使用时交付命令要加 `--allow-blue-purple "题材:夜空/深海/梦境"`。荧光色必须是「浅色 + 高饱和」（pastel neon），不是深暗色。
4. **颗粒色永远比该套色板最厚的沙色深 15–20%**。用 `grain = darken(thickest_sand, 0.18)` 自动算，不要手调。
5. **不要加灰色、黑色当沙色**。沙画的暗部来自「厚沙堆积」，不是用黑色颜料。沙色里最暗的那个（sandColors[0]）的亮度 L 不能低于 30（HSL 的 L）。

## 你想加一套新色板？

至少先满足：
- 在至少 1 段 ≥3s 的 scene 里用了，渲出来的静帧被审片标为「一眼沙画」（不是「颜色好看但像水彩/蜡笔」）。
- 该段的 qa：颗粒层、光台透光层都通过了（qa 第 2.1 节 1–3 条）。
- 连续 3 段不同构图用了这套色板，观感一致。

满足后把这套色登记进上表，同时写进 `SAND.palette()` 函数的 case 分支里。
