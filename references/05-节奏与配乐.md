# 05 · 节奏与配乐：让沙画的动作卡上拍

> 沙画天然带物理节奏：沙粒落一下「哒」、手指划一下「唰」、手掌一抹「呼——」。把这些声效和背景音乐的 BPM 对齐，片子质感直接上一个台阶。

## 一、默认节拍网格

沙画默认 **100 BPM**（比艺术动画的 128 慢，因为要留给观众看「画出来的过程」）。四分音符 = 0.6s，八分音符 = 0.3s。

剪点、转场、撒沙、划痕的起始/结束点**尽量全落在八分或四分音符拍点上**。不用完全卡死，但偏差不超过 0.05s（观众能感觉到）。

节拍网格在 `engine.js` 里由 BPM 驱动，`eras.js` 每段写的是「占几个八分音符」（eighths）而不是秒数。引擎会按 BPM 算出真正的时长。这样以后要调速（比如从 100→110）只改 BPM，段落表不用动。

例：一段占 6 个八分音符，100 BPM 时 = 1.8s；120 BPM 时自动变成 1.5s。

## 二、沙画动作和拍点的对应关系

| 拍点类型 | 音乐上的感觉 | 沙画应该在这一瞬间做什么 |
|---|---|---|
| 强拍（重音） | 「咚」 | 撒沙开始落下 / 手掌抹平结束露出新画面 / 一条主划痕划到终点 / 画面定格 |
| 弱拍 | 「哒」 | 小划痕起手 / 沙粒流动方向变 / 光台微闪一次 / 角落撒沙加一批新粒 |
| 切分（反拍） | 空半拍再「咚」 | 转场中点（旧的 50% 没了，新的 50% 出来了）/ 沙飘散转场中最稀疏那一帧 |
| 长音持续 | 一个和弦拉 4 拍 | 一道长划痕慢慢延伸 / 沙从左流到右（不跳，匀速）/ 光台呼吸起伏一个周期 |
| 休止符（静音瞬间） | 突然没声 | 画面刚好停在一幅完整沙画上、所有动作停（或只剩极慢的光台呼吸） |

## 三、合成声效（纯代码，不用额外素材）

`scripts/audio/sand_sfx.py` 里有 6 种沙画专属合成声效，全部是数学噪音合成，确定可重现：

| 声效 id | 触发时机 | 合成方法 |
|---|---|---|
| `sfx_pour` | 撒沙开始 | 白噪音通过高通＋快速衰减包络（0.02s 起音 → 0.25s 衰减），音量随沙量增加 |
| `sfx_scratch` | 划痕起手 | 棕色噪音短脉冲（0.08s）＋ 0.3kHz 中频峰，手指划沙的「唰」 |
| `sfx_wipe` | 手掌抹平 | 粉色噪音 0.6s 线性起音 → 线性衰减，音量从 0→0.7→0，抹平的「呼——」 |
| `sfx_drop` | 一粒大沙落下 | 正弦波快速下滑（2kHz→200Hz，0.05s），哒哒哒 |
| `sfx_light` | 光台亮起/划痕最亮瞬间 | 纯正弦 4kHz 极短（0.03s）极低音量，「叮」的空气感，观众不会听到但会觉得画面「亮了一下」 |
| `sfx_wind` | 沙粒飘散转场 | 白噪音通过带通（中心 1kHz，Q=2）＋慢起伏包络 0.8s，风声 |

用法：`eras.js` 段落表里 `sfx: [{t: 0.3, id:'sfx_pour', vol:0.6}, ...]`，引擎按 t 触发，`render.py --audio` 时自动合成＋混音。

## 四、BGM（音乐）模板

`scripts/audio/templates/` 下有 4 条沙画风格配乐模板，都是 100 BPM、纯代码合成（MIDI 合成器＋采样器）：

| 模板 | 情绪 | 乐器配法 | 适合 |
|---|---|---|---|
| `tmpl_warm_piano` | 温暖、回忆、治愈 | 钢琴（中低音区分解和弦）＋ 低音提琴长音 ＋ 远处偶尔沙粒 sfx_pour | 人物、情感、回忆类 |
| `tmpl_guitar_folk` | 清新、叙事、旅途 | 木吉他分解＋卡林巴琴（像沙粒敲击的高音）＋ 手鼓 | 风景、叙事、成长类 |
| `tmpl_cinematic_strings` | 宏大、震撼、史诗 | 弦乐群＋定音鼓滚奏（撒沙时）＋铜管长音（画面定格时） | 品牌、宏大叙事 |
| `tmpl_glow_ambient` | 梦幻、夜空、奇幻 | 合成器 pad＋不规则 bell 音色（对应荧光颗粒闪烁）＋几乎无打击 | 夜间荧光沙风格、梦境题材 |

每条模板都是 32 小节循环，有 pre-built 的起承转合。用法：
```sh
uv run scripts/audio/templates/tmpl_warm_piano.py --bpm 100 --duration 60 --out 配乐.wav
# 配乐是纯乐器，不含人声声道
uv run --with playwright python 工程/render.py --out 成片.mp4 --audio 配乐.wav --audio_mix 0.35
# audio_mix 是 BGM 相对画面声效的音量，默认 0.4（人说话时降到 0.15）
```

## 五、卡节奏的具体做法（一步步）

1. 先算 BPM：从 `eras.js` 算好每段起止的**绝对时间戳**（秒），列成表。
2. 把每个沙画动作（撒沙起、划痕终点、抹平分界点、定格）标到表上，看哪些在拍点上、哪些偏。
3. 偏差 > 0.05s 的：要么调动作的速度（撒沙快一点/慢一点），要么调 eighths 数（让整个段长短一两个八分音符），**动作对齐拍点优先于整数秒数**。
4. 写 sfx 触发表：`eras.js` 的每段 `sfx` 数组，把 sfx 标在动作点上（和动作同一个 t，不做额外延迟——声音和画面同时发生观感最好）。
5. 渲一条无音乐只有声效的 48kHz wav：`render.py --out test.mp4 --sfx_only`，耳朵听一下 sfx 时机对不对，不对就调 sfx 的 t±0.02s。
6. 最后加 BGM：`--audio 配乐.wav --audio_mix 0.35`。出片后先看一遍**没有画面只听声**：如果单听声就能听出节奏变化和关键瞬间，说明节奏是对的。

## 六、踩过的坑

- **BPM 选得太快**（比如 140），撒沙还没落完下一拍来了，观众看不清楚作画过程。沙画 90–110 BPM 之间最好。
- **转场中点没对齐切分拍**，会有「画面动了但音乐没跟上」的脱节感。转场中点 = 转场开始 + 转场时长/2，一定要把这个时间点标在切分拍或反拍上。
- **sfx 音量太大**，盖过 BGM。sfx_pour 最大音量 0.6，其他 sfx ≤0.45。观众应该是「感觉有声音在配合动作」而不是「听到沙粒在响」。
- **BGM 每小节都有强鼓点**，像舞曲，和沙画的温柔质感不搭。沙画 BGM 打击乐要轻、要稀疏；重拍靠和弦变化而不是鼓点来标。
- **光台呼吸跟 BPM 的长音不同步**，呼吸周期如果是 3 秒但 BPM 一个小节是 2.4 秒，会有视觉和听觉的相位差，画面发飘。光台呼吸周期写成 `4*60/BPM` 秒，自动和音乐的 4 拍小节对齐。
