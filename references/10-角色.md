# 10 · 角色：沙画里要出现人怎么处理（AI 生帧＋沙画化合成 / 只出手和背影）

> 适用于：沙画短片里要出现主角、用户本人形象、真人角色、拟人吉祥物。
> 沙画里的人和普通艺术动画不一样：人脸必须用 AI 生图后再沙化，不能代码手画。没生图能力就走「极简剪影法」，绝对不要代码画五官。

## 一、三条路（按你的素材和能力选）

| 方案 | 你有 | 视觉 | 制作成本 | 质量线 | 读 |
|---|---|---|---|---|---|
| A · AI 生帧→沙画化合成 | 当前会话有 AI 生图工具、或用户提供了人物照片/参考 | 能看出是那个人，同时是沙画风格 | 中（生图 + 沙化滤镜 + 代码合成） | ★★★★★ | 第三节 |
| B · 手/背影极简剪影 | 没有任何素材，或人物只出现在远景/背影 | 只画手、背影、侧影，没有脸 | 低（纯代码画沙画剪影） | ★★★★（足够好看） | 第四节 |
| C · 帧库逐帧替换 | 已有角色帧库（PNG 序列，透明底） | 角色是沙画风格，逐帧换动作 | 中（帧库准备 + 合成） | ★★★★★ | 第五节 |

**绝对禁止：代码手写五官（眼睛/鼻子/嘴/脸型）。** 沙画的手画五官会变成「简笔画小人」，非常 AI 味。

## 二、先判断精细度（照 `角色精细度.md` 锁方案）

| 精细度级别 | 场景 | 允许方案 | 不允许 |
|---|---|---|---|
| F0 · 完全无角色 | 纯风景、纯图表、纯图形 | 不用做角色 | — |
| F1 · 只出手和背影 | 叙事里人只是「那个在沙上画画的人」；镜头永远不拍脸 | B 方案（剪影） | A/C（不需要人脸就别画） |
| F2 · 侧影/远景 | 人站在海边或窗边，只看到轮廓，不看脸 | B 方案（剪影升级版） | A（看不清脸就别浪费算力） |
| F3 · 中景、看得到脸 | 讲故事时镜头切到人物正面，脸要认得出来 | A 或 C 方案 | B（剪影顶不住了） |
| F4 · 特写、表情变化 | 近景镜头、要表现喜怒哀乐 | A/C + 帧序列（表情 5 姿以上） | B 完全不行 |

镜头表写好以后，先看哪几镜有人、每镜是 F1–F4 哪级，再按上表选方案。一整片里如果既有 F1（背影）又有 F3（正脸），**混用 A+B**：背影/手用纯代码剪影，正脸用生帧沙化。不要为了一致把背影也用生帧，浪费算力。

## 三、方案 A · AI 生帧 → 沙画化合成（两步法）

### Step A1 · 出沙画师角色帧

用当前会话的 AI 生图工具（或调用 `scripts/images.py gen`，读 `references/images.md`），对每个 F3/F4 镜头出至少 3 张候选图。Prompt 模板（直接抄，把括号里的换掉）：

> 「沙画风格肖像，(Cooper 的特征：40 岁亚洲男性，短发，戴眼镜，穿深色西装)，从沙台上的暖黄背光台透出来，厚沙堆出脸部阴影，划痕亮线勾出轮廓和五官线条，颗粒感 3px 粗沙，边角有正在撒沙的痕迹，光台暗角，画面整体暖金暖棕，没有蓝紫，没有霓虹色，真实沙台摄影风格，1920×1080，—no 卡通 AI 感 光滑皮肤 塑料感 矢量图 渐变底 蓝紫色」

让工具产出 3 张方向不同（正面/微侧/半身），给用户挑一张（硬门三方向）。用户挑了那张后，**用它作为 seed 图，出这个角色所有镜头的帧**（保持一致性）。

### Step A2 · 沙化滤镜＋代码合成

**不要直接把生图贴进沙画视频**（那是贴图，不是融入）。用 `SAND.sandifyPhoto(rawPhoto, depthMap)`：

1. 把生图降采样到 480×270 得到亮度图。
2. 亮度图 → 沙厚图：`sandThickness = 1 - luminance^γ`，γ=1.4；厚沙区域在暗、薄沙在亮。
3. 沙厚图 → 用本沙画风格的标准渲染器（`SAND.compositeFromThickness`）重新画一遍：光台底＋按厚度插值的沙色＋按厚度插值的颗粒数。
4. 把合成出来的沙画人像，**叠进你 scene 里的沙层**（用 `multiply` 或 `source-atop`），不要作为一个独立图层贴在沙台上面——要把人像「融进沙台」里。
5. 在人像**轮廓线外加一圈划痕亮边**（`SAND.scratchLine` 沿轮廓走一遍），模拟「沙画师专门勾了一条轮廓把人像勾出来」。

### Step A3 · 验收（不过就重生图）

- [ ] 沙画化后人像**颗粒随沙厚变化**（不是一张整图加噪点滤镜）
- [ ] 人像最薄处透出光台色（不是生图本身的亮处颜色）
- [ ] 勾边划痕是亮线（不是深色描边）
- [ ] 放远看（缩到 20%）还**一眼认出是那个人**（认不出就重新出图，别在沙化滤镜上救）

## 四、方案 B · 只出手和背影（纯代码剪影，推荐）

大部分叙事沙画短片**根本不需要正脸**。手和背影在沙画里辨识度极高（因为沙画本来就是「一双手在台上画」的艺术形式）。用这个方案，不需要生图工具，纯代码 `SAND.drawSilhouette()` 就够，质量也高。

### 可画的形状（都在 `lib/sand_paint.js` `SAND.SIL.*`）

| 剪影 id | 形状 | 用法 |
|---|---|---|
| `SAND.SIL.hand_palm_down` | 一只手掌（朝下，正在抹平沙） | y3 抹平转场的手；scenes 里「画完最后一笔的手收回去」 |
| `SAND.SIL.hand_finger_draw` | 一只手（指尖朝下，正在划线） | y1 白板手划的手；所有主划痕上叠一只手悬在末端 |
| `SAND.SIL.person_back_stand` | 一个人背影站着（长发短发两版） | 场景人物远景；「面对一幅大沙画看」 |
| `SAND.SIL.person_side_sit` | 一个人侧影坐着（伏案姿势） | 画面里画师本人；故事里的角色坐着 |
| `SAND.SIL.couple_back_walk` | 两个人背影牵手走 | 情感类；旅途类结尾 |
| `SAND.SIL.child_and_adult_hand` | 大手牵小手的剪影 | 成长、亲子、传承类题材 |

### 调用

```js
// 在 scene draw() 里，第 5 层（划痕）之后，第 6 层（作画痕迹）之前画
const handP = SAND.drawSilhouette(c, C, SAND.SIL.hand_finger_draw, {
  x: 划线末端_x + 20,
  y: 划线末端_y - 80,
  size: 180,          // 像素高度
  rotation: 0.2,      // 弧度
  mode: 'medium_sand' // thick_sand=深色剪影 / medium_sand=稍透一点光
});
// 返回的 handP 是那只手占的矩形区域，后面手掌抹平时 wipe 区域可以用这个
```

### 验收（方案 B 必过）

- [ ] 剪影形状完整，没有断笔（手的手指 5 根都看得到）
- [ ] 剪影是**沙堆出来的**（有颗粒、有 roughEdge、不是矢量 Path 直接 fill）
- [ ] 剪影边缘**没有完美几何边**（已经过 roughEdge）
- [ ] 大小合适：手的大小是画面高度的 15–20% 左右；人背影占画面 40–60% 高。太小看不清，太大像剪纸贴上去。

## 五、方案 C · 帧库逐帧替换

已有角色帧库（PNG 序列，透明底），逐帧 `drawImage` 贴进沙台层之前先过 `SAND.sandifyPhoto()`（和方案 A2 同函数）。

如果帧库本身就是沙画风格（已经有颗粒和透光），沙化滤镜参数调弱（`onlyAddGrain=true` 只补颗粒不重算沙厚）。如果帧库是普通卡通风格，沙化滤镜按标准参数跑。

帧库之间的动作切换要做「5 帧线性 dissolve」（两帧半透明叠 0.15s），不要硬切——沙画的颗粒层连续，动作切太硬会闪。

## 六、踩过的坑

- **方案 B 给手画了指甲和掌纹**，变得很奇怪。剪影就是剪影，内部细节一律不要。手的形状就是一块深沙轮廓。想表达「手指在划」，用划痕末端的位置和手的旋转来表达，不画掌纹。
- **方案 A 的沙化参数调太狠**，人像的脸变成一团深沙，五官都没了。调整 `gamma_thickness`（默认 1.4，调到 1.1 人脸更薄更透，五官更出）。
- **F1 级的镜头硬上 A 方案**，结果人脸占画面 2%，根本看不清。浪费了算力还拖慢了渲染。按精细度表选。
- **手的尺寸和场景不匹配**，手看起来像怪物手掌。hand 的 size 公式：`画面H * 0.18`（±10%），如果手是「远一点的」就 0.12 倍。
