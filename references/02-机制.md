# 02 · 机制：一段沙画动画为什么「有那味儿」

> 这一页是所有沙画短片（不只是穿越类）的通用机制：五层感知模型。单一风格片、故事片、解说片都照这个搭骨架。

## 五层机制（从低到高）

### 1. 光台底层——「我在看一张沙画」

观众第一秒识别这是沙画，靠的是**光台的透光感**，不是沙粒。

- 光是暖的（黄/白），从下往上透。无沙处＝亮，沙厚处＝暗。
- 画面四角比中心暗 8–12%（真实沙台的边缘光弱）。
- 沙画的「线条」本质是**划痕（刮掉沙露出亮底）**，不是「用深色沙画上去的线」。反常识但这是真的：拿张沙画看，亮线才是手划的，暗的是没动的沙堆。

→ 代码实现：`SAND.lightTableComposite()`，永远在最底层。

### 2. 颗粒中层——「这些真的是沙粒」

光台+渐变能做出「有明暗」，但没有颗粒感就会被读成「一张黄色渐变图」。

- 颗粒大小 ≈ 1–3px（标准沙），不是 0.5px 的噪点也不是 10px 的斑块。
- 颗粒**不是匀质**的：厚沙区颗粒密、深；薄沙区颗粒疏、浅；无沙区颗粒为 0。
- 颗粒位置**不是每帧换**：30fps 的片，颗粒 10–12fps 换一次种子——每 3 帧跳一下，肉眼读成「细沙在微微滚动」，不是「画面在闪」。

→ 代码实现：`SAND.grain()`，按局部沙厚调整颗粒强度。

### 3. 作画过程层——「一只手正在画」

观众看到沙画时默认会脑补有一只手在上面。你要**喂给这个脑补信息**：

- 每一镜保留 1–2 处「正在画」的痕迹：
  - 划痕末端在延长（亮线越来越长）
  - 一角有沙粒正在落下（撒沙中）
  - 画面边缘有被手掌推过的扇形残影
- 画面永远**不完美**：总有些地方沙铺得不均匀、总有些划痕的末端是毛的。完美无瑕＝不是手画的＝没有温度。

→ 代码实现：母题 m1–m6（`风格配方/01_classic_warm.md` 第三节），每镜至少上 2 个。

### 4. 转场签名层——「这是沙画特有的切换」

PPT 淡入淡出是通用的，观众无感。**撒沙、抹平、飘散、流动**这四种是沙画独有的，一出现观众就会「哦！沙画！」。

- 转场不要从通用库里挑，要**从沙的物理行为里长出来**：
  - 时间流逝 → 手掌抹平（时间像手一样擦掉旧画面）
  - 揭示答案 → 手指划开（答案像一条线被划出来）
  - 情绪爆发 → 沙粒飘散（画面被吹散，情绪被释放）
  - 空间转移 → 沙粒流动（物体的沙自己流过去重组）
- 每次转场，**光台会有 0.1s 的微闪**（±5% 亮度），对应真实沙台上画师做动作时手遮住了一点光。这个小细节做了，转场就会有「真实的手感」。

→ 代码实现：`scripts/engine/transitions.js` 里 `t_*` 系列，都内置了光台微闪。

### 5. 节拍网格层——「剪点卡得舒服」

沙画作画是物理过程，有自己的时间感。把剪点卡在 BPM 网格上，观众会觉得「节奏刚好」，即使没配乐。

- 默认 100 BPM（比艺术动画的 128 慢，因为沙画要留给观众看「画的过程」），剪点落在四分或八分音符。
- 每镜时长：
  - 「撒沙成一幅简单画」 → 1.2–1.8s（够看成形）
  - 「手指勾出细节」 → 0.8–1.2s（快动作，不拖沓）
  - 「手掌抹平转场」 → 0.4–0.6s（不拖）
  - 「情绪停顿（最后一镜）」 → 3–5s（让观众看）
- 不要所有镜都一样长。做成「快-快-慢-快-快-慢」的节奏，观众不会困。

## 换题材时怎么用（举例）

| 层 | 默认沙画短片 | 换成「用沙画讲李白的一生」 |
|---|---|---|
| 光台 | 暖黄光台 | 暖黄光台＋每镜光台色随时间偏色（青年偏亮、中年偏暖、晚年偏暗） |
| 颗粒 | 标准沙 2px | 青年细沙 1px、中年标准 2px、晚年粗沙 4px（颗粒随人生变粗） |
| 作画过程 | 每镜 2 个母题 | 每段人生出场都用「撒沙成形」，去世一镜用「沙粒飘散」 |
| 转场 | 四签名随机选 | 人生阶段切换用「手掌从左抹到右」（时间之手）；关键事件用「手指划开」（翻开人生一页） |
| 节拍 | 100 BPM | 年轻时 110 BPM（快），晚年时 75 BPM（慢），节拍本身在讲故事 |

## 不要学歪

- 不要把 5 层当成检查清单每次都照抄。这 5 层是「为什么一段沙画好看」的解释框架，不是模板。你的第一支片可以只做 1+2+4 就交付，后面再加 3 和 5。
- 不要把「颗粒」放在光台下面。颗粒必须在沙层上、随沙厚变化，否则就是一张全局噪点滤镜，观众会读出来。
- 转场的「光台微闪」不要做大。±5% 就够，大了像坏屏幕。
