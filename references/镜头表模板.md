# 镜头表模板：沙画短片镜头表

> 把下面的内容复制到 `<项目>/镜头表.md`，按你的题材填写。填完之后：
> 1. 跑 `uv run <skill>/scripts/storyboard_lint.py <项目>/镜头表.md`（有口播加 `--script 文稿.txt --align 时间轴/逐句对齐.json`）
> 2. 红灯没清不要开始写代码。

## 表头（镜头表之前，先锁这三项，全片不动）

```yaml

色板: 暖沙标准-5色              # 从 references/色板.md 抄 name 字段（中文名那列）。全片一致。
角色: 只出手和背影              # 无 / 只出手和背影 / 帧库 路径=<绝对路径>
                                 # 「帧库」选这个先过 references/角色精细度.md 的 F3/F4 检查
BPM: 100                        # 默认 100。改这个的话写清楚为什么（比如「110 儿童片节奏」）。
```

## 填表注意事项（写之前读，lint 会查这些）

1. **第 1 镜（0.00s 起）的「做什么」必须包含沙画开场动作**：`撒` 或 `划` 或 `光台亮起` 三个词至少出现一个。lint 的 rule: OP01。
2. **最后一镜的「镜头」列必须包含「停 ≥3 秒」和「淡出黑场」**。且不能包含「抹平」「飘散」「擦除」字样。P10 经验。
3. **「画面里的物」列：不能空，不能写抽象词**。写「沙画堆成的四个柱子」不是写「营收增长」。空镜 / 纯黑场 / 纯色 = lint 红灯。
4. **「它在做什么」列：至少每两镜里有一镜包含沙画行为动词（撒/划/抹/流/散/聚）**。全表只出现「淡入」「淡出」「缩放」 = 翻页 PPT，红灯。
5. **「转场名」列：除了前后两镜都是纯图表的可以硬切，其他相邻两镜之间必须是沙画签名转场（t_* 开头的那 6 个之一）**。写「硬切」超过 20% 的镜头对 = 红灯。
6. **屏上字每镜 ≤8 字**。超过写数组分行（`[第1行≤8, 第2行≤8]` 这样写）。单镜超过 3 行也红灯。
7. **时间段精确到 0.01 秒**。不要写「~2 秒」。按 BPM（默认 100，八分 = 0.3 秒）四舍五入。两镜之间间隔必须 0.00。
8. **「做法」列：同一个语法 id（y1~y8）不要连续出现 4 次以上**。会变成同一种动画放 4 遍，观众腻。
9. **画风/色板/角色 三个表头值，整支片只出现一套**。如果中途想换（比如从暖沙切彩沙），必须是「片中片」结构（一段「打开了一本彩色绘本」）且要有理由写进表头的 notes。没有理由的中途换色 = 红灯。
10. **相邻两镜的主物不要完全相同构图 + 完全相同位置**。会被读成「同一帧字变了」不是「下一镜」。至少改一个：主物位置、镜头位置、沙画厚度。
