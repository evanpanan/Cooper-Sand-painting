# 03 · 一帧先行四条路线：先出一幅对的沙画静帧，再让它动

> 第一次做沙画的话，90% 的错误出在「第一幅画本身不对」。先把一帧做对，动画自然就对了。

## 四条路线（按你手上有什么选）

| 路线 | 你有 | 做法 | 时间 | 适合 |
|---|---|---|---|---|
| A · 配方直出 | 没有参考，完全从零写 | 从 `风格配方/INDEX.md` 三选一，抄它的色板和五层顺序，画一个跟你的题材有关的简单形状 | 20–30 分钟 | 第一次做沙画、题材简单 |
| B · 参考图沙画化 | 有一张图（照片/插画/ logo）要做成沙画 | 拿图进「沙画化流程」，先出静帧再出动画 | 40–60 分钟 | 有具体视觉参考的题材 |
| C · 样片逐帧抄机制 | 有一段沙画视频参考，想复刻它的画法 | 按 `01-拆解.md` 拆出第一镜的关键帧，照它的作画顺序抄机制（不抄像素） | 60–90 分钟 | 复刻、学别人的画法 |
| D · 三方向硬门 | 不确定方向或要给用户选 | 先出三个方向完全不同的静帧（不同构图＋不同颗粒感），给用户挑一个再继续 | 3×30 分钟 | 用户要「做得好看」但没说方向、或交付前需确认 |

用户没指定方向时默认走 A＋D：先按 A 出 1 张，再补 2 张凑 3 个方向给用户挑。

## 路线 A · 配方直出（例：题材是「一朵花」）

1. 选风格：默认 s01 经典暖沙。
2. 建空工程：`cp -R scripts/engine /tmp/sand_try`。
3. 写 scene：`scenes/temp_flower.js`

```js
SCENES['temp_flower'] = {
  draw(c, lt, t) {
    const C = SAND.classicPalette();
    SAND.lightTable(c, C);                          // 1. 光台
    SAND.thinBed(c, C, 0.55);                       // 2. 薄沙床
    // 3. 厚沙画花的剪影（形状 roughEdge 过）
    const petal = (cx, cy, r, rot) => ellipsePath(cx, cy, r*0.7, r, rot);
    for (let i=0;i<6;i++) {
      const a = i * Math.PI/3;
      SAND.dabShape(c, C, petal(960+Math.cos(a)*120, 540+Math.sin(a)*120, 100, a), 'thick');
    }
    SAND.dabShape(c, C, circlePath(960,540,80), 'thick'); // 花心
    // 4. 划痕透光：花瓣上的亮纹
    for (let i=0;i<6;i++) {
      const a = i * Math.PI/3;
      SAND.scratchLine(c, C, [960,540], [960+Math.cos(a)*180, 540+Math.sin(a)*180]);
    }
    // 5. 痕迹：右下角在撒沙 + 一条花瓣纹还在延伸
    SAND.pourCorner(c, C, 1700, 900, 0.3, t);
    SAND.scratchGrowing(c, C, [960,540], [960+180, 540], 0.3, t);
  }
};
```

4. 出静帧：`uv run --with playwright python scripts/engine/render.py --solo temp_flower --stills 2 --out /tmp/sand_try/flower`
5. 打开 `flower_002.png` 看。对照 `02-机制.md` 的 1/2/3 层：
   - 透光吗？划痕处是不是明显比周围亮？→ 不亮就调 `scratchLine` 的深度。
   - 有颗粒吗？颗粒是不是只在沙上、不是整屏噪点？→ 不对就查 `grain` 参数。
   - 有作画痕迹吗？右下角的撒沙和生长线能看出来吗？→ 痕迹不明显就加量。

改 1–2 轮就对了。一帧对了，整段动画就只是这个 scene 的 draw(t) 慢慢展开。

## 路线 B · 参考图沙画化（流程）

1. 进参考图：`SAND.loadReference('/tmp/ref.png')` 到离屏 canvas R。
2. 灰度化 R 并降采样到 480×270，得到亮度图 L。
3. 三层合成：
   - 光台层：沙画标准光台色。
   - 沙厚层：`sandThickness(x,y) = 1 - L(x,y)`。参考图越亮→沙越薄→越透光。参考图越暗→沙越厚→越暗。这一步把照片明暗映射成沙台明暗。
   - 颗粒层：按 sandThickness 加颗粒，和 A 路线一样。
4. 人工加划痕和作画痕迹（自动生成的痕迹太假，这步必须人工写）。
5. 出静帧，对照参考图看「是不是还认得出来」。太像原图＝沙化不够，要增加颗粒、增加几道明显划痕、增加作画痕迹。

沙化程度的标准：**把沙画版和原图摆在一起，别人一眼能认出是同一个东西，但也一眼能看出是「沙画版」不是「原图加滤镜」。**

## 路线 D · 三方向硬门（三个方向怎么凑够不同）

别偷懒只调色调。用户要的是方向选择，不是选色板。三个方向至少要在**两个维度**上不同：

- 维度 1：构图 —— 居中特写 / 对角构图 / 全景留白
- 维度 2：颗粒感 —— 细沙（精致）/ 标准沙（自然）/ 粗沙（粗粝）
- 维度 3：作画痕迹风格 —— 干净少痕（专业感）/ 多痕（手作感）/ 大量撒沙未完成（艺术感）

举例「一朵花」的三个方向：
1. 细沙＋居中特写＋花瓣亮划痕少 → 精致、适合品牌片
2. 标准沙＋对角构图（花占左下）＋花瓣亮划痕多 → 自然、适合故事片
3. 粗沙＋全景留白（花只占画面 1/4，大片沙台）＋右上角大量撒沙痕迹 → 粗粝艺术感

用户挑了哪个，后面整支片就锁定这个方向的所有参数。

## 踩过的坑

- **静帧看起来像沙画，动起来不像**：因为你只静帧检查了第 1 层（光台）和第 2 层（颗粒），没检查第 3 层（作画过程）。静帧通过后，一定要渲 3 秒（`--from 0 --to 3`）看动态的痕迹。
- **路线 B 做出来像「原图叠了个沙滤镜」**：因为沙厚层直接用了 1-L，完全忠实原图明暗。正确做法是沙厚层只保留大尺度明暗（48×27 下采样后双线性放大），细节的划痕和颗粒不来自参考图，是沙画自己的。
- **三个方向用户挑了方向 2，但你舍不得方向 1 的某个细节**：不要混。挑了哪个就锁哪个，混了方向＝没有方向，最后整支片的一致性会崩。
