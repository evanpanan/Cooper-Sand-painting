# 11 · 长卷沙画：一张沙台从左画到右，跨区换画面

> 适用于：「一个人从沙台左端走到右端，每走一步画面前进」「从左到右的时间线」「一个人穿过一幅幅沙画」。
> 机制跟普通分段片不同：沙台是一张无限长画布，镜头从左往右匀速推进，走到哪个区就画哪个区的内容，跨区时用流动转场。

## 一、骨架

```
scripts/engine/demos/long_sand_scroll/
├── eras.js               # 不是分段时间表，是分区坐标表
├── scenes/
│   ├── zoneA_start.js    # 起点区：撒沙成第一幅画（画面主体在左端）
│   ├── zoneB.js          # 过渡区1：沙粒流动，从 A 画面的形状渐渐变成 B 画面的形状
│   ├── zoneC_main.js     # 中区：主画面，最完整的一幅
│   ├── zoneD_end.js      # 终点区：最后一幅，手指划完最后一笔，停留
└── engine_patch.js       # 把原 engine 的「按 t 切分段」改成「按 scroll_x 切区」
```

核心数据结构：
```js
// eras.js（长卷版）不是 eighths，而是像素坐标
const ZONES = [
  { id: 'A', x_start: 0,    x_end: 1200,  sceneId: 'zoneA_start',
    enter_transition: 't_pour_in_at_x_0' },
  { id: 'B', x_start: 1200, x_end: 2400,  sceneId: 'zoneB',
    enter_transition: 't_sand_flow_from_left' },
  { id: 'C', x_start: 2400, x_end: 3800,  sceneId: 'zoneC_main',
    enter_transition: 't_sand_flow_from_left' },
  { id: 'D', x_start: 3800, x_end: 5000,  sceneId: 'zoneD_end',
    enter_transition: 't_finger_draw_reveal' }
];
const SCROLL_SPEED_PX_PER_S = 180;   // 镜头每秒推多少像素
const SCREEN_W = 1920;
```

时长自动算：`totalDuration = (ZONES[-1].x_end + SCREEN_W) / SCROLL_SPEED_PX_PER_S`。不要手动算，改速度就行。

## 二、每区的 scene 要怎么写

长卷的 scene 和普通 scenes 有三个关键不同：

1. **坐标系是长卷的绝对 x**，不是屏幕 x。draw(c, lt, t) 的第一个参数 c 是长卷离屏 canvas（5000×1080，不是 1920×1080）。你画的每一个点都直接用长卷绝对坐标，不用管相机。
2. **只画本区＋左右各 200px**，其他区的内容别画。引擎会帮你 clip 到 `[x_start-200, x_end+200]`。不要一个 scene 画 5000px 全宽——会互相覆盖、颗粒缓存炸。
3. **区与区的交界线 200px 宽做流动融合**。不是 A 画面突然切 B 画面，是 A 的沙顺着流动方向慢慢散、B 的沙顺着流动方向慢慢聚。融合只在交界带做，和彩沙层融合的 P9 经验一样。

### 典型 zone 的 draw()

```js
SCENES['zoneC_main'] = {
  // meta 里多加两个字段
  meta: { x_start: 2400, x_end: 3800, ... },
  draw(c, lt, t) {
    const xs = this.meta.x_start, xe = this.meta.x_end;
    const C = SAND.classicPalette();
    // 注意：所有形状坐标是长卷绝对坐标。主物放在 (xs + (xe-xs)/2, 540)（区中心）
    const cx = xs + (xe - xs) / 2;
    const cy = 540;
    // 主体厚沙：一朵花，区中心
    SAND.dabShape(c, C, circlePath(cx, cy, 180), 'thick');
    // 花瓣划痕
    for (let i=0;i<6;i++) {
      const a = i * Math.PI / 3;
      SAND.scratchLine(c, C, [cx, cy], [cx+Math.cos(a)*260, cy+Math.sin(a)*260]);
    }
    // 作画痕迹：右端边缘还在画（因为镜头正推进来）
    if (t < 8.0) {
      const growing = (t/8.0) * (xe - xs);
      SAND.scratchGrowing(c, C, [cx, cy], [cx + 260, cy], 0.3, t);
      SAND.pourCorner(c, C, xe - 40, 200, 0.2, t);  // 右上角撒沙
    }
  }
};
```

## 三、角色「走」过长卷

长卷里的人物走法跟普通分段片不一样：**不是切分段时换位置**，是人物的 `_scroll_x = SCROLL_SPEED_PX_PER_S * t` 直接跟着镜头走，每帧在长卷离屏 canvas 的 `scroll_x + SCREEN_W*0.3` 这个位置画人物（画面左边三分之一）。

人物跨区时：**只在人物那一帧所在的区里画人物**，别每个区都画。人物大小和姿势按区换（A 区出场→C 区最大→D 区走出画面或停下），但 x 坐标永远是滚动的计算值。

如果人物要「在 C 区停 5 秒」：SCROLL_SPEED 不是常量，是 piecewise 函数：
```js
const SCROLL_SPEED = (t) => {
  if (t < 8) return 180;                          // 正常推
  if (t < 13) return 0;                           // 在 C 区停 5s
  if (t < 20) return 160;                         // 放慢推进
  return 180;
};
```

人物的 `_scroll_x` 用积分（`∫ speed`）算，不是线性乘 t。引擎 patch 里已经写好了积分器，改 `SCROLL_SPEED` 函数即可。

## 四、长卷的镜头推进的「沙画感」怎么来

普通横屏镜头平移是「画面在动」。长卷沙画的横移要像「沙画师的手一直在画面右侧的新沙台上往下画」，所以必须：

1. **屏幕右边缘永远有「正在作画」的痕迹**：每个区的 scene 在 `x_end - 150` 到 `x_end` 这 150px 宽区域，永远有撒沙或划痕在生长（见上面 zoneC 的 if (t<8.0) 块）。这 150px 就是「刚被画完但还带着手的温度」的地带。
2. **屏幕左边缘永远有「已经被抹掉一半」的淡出**：每个区在 `x_start` 到 `x_start + 150px` 区加一层半透明的「被手掌扇过的残影衰减」（`SAND.wipeTrail` 从左向右淡）。左右一进一出，长卷的推进就是「画师在右画、观众在左看、中间看故事」。
3. **区之间的融合用「流动」不用硬切**：`t_sand_flow_from_left`（沙粒从左流向右）的转场，只在交界 200px 带做。观众看到的是「这边的沙流过去变成那边的沙」不是「这边结束那边开始」。

## 五、快速上手（复制示范再改）

```sh
# 1. 复制整个 demo 工程
cp -R scripts/engine 我的长卷/代码工程
cp -R scripts/engine/demos/long_sand_scroll/* 我的长卷/代码工程/

# 2. 改 eras.js 的 ZONES 表：改 x_start/x_end、sceneId、画面内容
# 3. 改 scenes/zone*.js 的形状、主物、作画痕迹
# 4. 渲一版 2 倍速的快放预览（快速看整体节奏）
uv run --with playwright python 我的长卷/代码工程/render.py \
  --long_scroll --speed 2.0 --out 我的长卷/快放.mp4 --fps 15

# 5. 渲全片
uv run --with playwright python 我的长卷/代码工程/render.py --long_scroll --out 我的长卷/成片.mp4 --fps 30
```

## 六、踩过的坑

- **一个 scene 画了全宽**，互相覆盖 + 颗粒缓存撑爆内存。严格 clip：scene 只画自己的 xs-200 到 xe+200。
- **右边缘的正在作画痕迹没做**，横移看起来像「一张超长图片在平移」。强制每个 zone 的 xe-150 到 xe 区有撒沙/growing 划痕。
- **人物坐标用屏幕坐标不是长卷绝对坐标**，每帧跨区时人就跳。人物 x 永远用 `_scroll_x + 屏幕_x_relative` 这个组合值。
- **SCROLL_SPEED 给太快**（>240 px/s），沙画还没看清就过去了。沙画长卷默认 150–200 px/s，比普通 PPT 长卷慢一倍。
- **交界融合带太宽**（400px+），中间一大段画面脏乎乎。按 P9：≤ 200px，绝不在整条区宽做融合。
