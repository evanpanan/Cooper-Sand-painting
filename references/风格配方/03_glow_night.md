# 风格配方 s06 · 夜间荧光沙·星河

> 适用：夜景、星空、梦境、科幻、奇幻。深蓝紫光台＋自发光颗粒。交付必须加 `--allow-blue-purple "主题是夜空/梦境/奇幻"`。

## 一、色板

```json
{
  "theme": "glow_galaxy",
  "lightTable": "#1A1040",
  "sandBase": "#2E1F55",
  "glowColors": [
    { "color": "#8FFF8F", "intensity": 0.9, "pct": 40, "name": "荧光绿" },
    { "color": "#FFB84D", "intensity": 0.85, "pct": 30, "name": "荧光橙" },
    { "color": "#FF8FCC", "intensity": 0.9, "pct": 20, "name": "荧光粉" },
    { "color": "#8FD8FF", "intensity": 0.8, "pct": 10, "name": "荧光青" }
  ],
  "grainColor": "#0E0825",
  "glowBlur": 3.5,
  "bloomStrength": 1.3
}
```

- 光台 `#1A1040` 是深靛紫，不是纯黑。无沙处透出这个色，做夜空的底。
- `sandBase` 是「不发光的普通沙」的颜色，铺厚沙用。星河的暗色背景就是这个色堆出来的。
- 荧光色只在「薄沙＋有激发光」处透出。加 `glowBlur` 和 `bloomStrength` 做辉光（Bloom），不然荧光就是纯色块。
- 颗粒用更深的 `#0E0825`，几乎是黑，压暗整张画让荧光显得更亮。

## 二、六层画法顺序（标杆 `scenes/s06_glow_galaxy.js`）

荧光沙的核心是**暗沙做主体形状，荧光颗粒只在「薄沙边缘、划痕、松散处」透出**，不是满屏亮。

1. **光台底（暗夜）**：`#1A1040` ＋非常淡的星点噪声（0.3% 像素，亮度 0.2）＋ 暗角。
2. **厚暗沙床**：整屏铺 `sandBase` 沙，厚度 0.8，颗粒强度 0.7。这是默认状态——沙台被暗沙盖满，不透光。
3. **构图形状（暗沙堆出剪影）**：把画面里的「非星空」区域（山、树、人物剪影、建筑）堆更厚的暗沙，几乎不透光。这些形状的边缘是**荧光渗出区**（最关键）。
4. **星空区（刮掉暗沙露光台＋撒荧光粒）**：在「星空区域」用 `SAND.scratchArea` 刮掉厚沙→ 露 `#1A1040` 光台 → 往这个区域撒荧光颗粒（按 pct 比例：40% 绿、30% 橙…）。每颗粒用 `SAND.glow` 画：颗粒本身＋3.5px blur 的同色副本＋ bloom 叠加。
5. **荧光流动（最亮的星）**：把几颗「主要的星」连成路径（星座连线），用 m9 荧光沿路径流动。如果是银河，用 m10 银河旋转。
6. **痕迹层**：一角有荧光沙正从沙漏落下（m11 沙漏撒荧光沙）；或一条星座连线正在画（m3 划痕延伸的荧光版）。

## 三、母题小循环

| id | 母题 | 视觉 |
|---|---|---|
| m9 | 荧光沿路径流 | 星座连线/银河边界的荧光颗粒每 3 秒完整流动一圈 |
| m10 | 银河缓慢转 | 大椭圆螺旋星系以 20 秒一圈缓慢旋转，整体不跳 |
| m11 | 沙漏撒荧光沙 | 画面一角一个虚拟漏斗每 5 秒倒出 200 粒荧光沙，在画面上漂开 |
| m12 | 星闪烁 | 每颗星的亮度乘 0.85-1.0 的随机系数，每 0.8 秒换一次值（不是每帧换） |
| m13 | 流星划落 | 每 8 秒随机出现一颗流星，拖尾 200px，在 0.6 秒内划过画面 |

## 四、签名转场

- **开场**：`t_void_to_galaxy`（1.0s）完全黑暗→光台暗紫亮起→荧光颗粒一颗颗从沙下冒出来聚成第一幅。
- **中段**：`t_supernova`（0.8s）画面中心一颗星爆炸→冲击波把旧画面的沙推向外圈→中心重新汇聚成新画面。
- **结尾**：`t_stars_fade`（1.0s）所有荧光颗粒慢慢熄灭→暗沙床→完全黑。

## 五、短板与避坑

| 坑 | 表现 | 修法 |
|---|---|---|
| 满屏亮成一片 | 荧光铺满整个画面，分不清星空和形状 | 荧光只在「刮掉厚沙」的区域出现；剪影区严禁荧光；亮/暗的反差要拉到最大 |
| 辉光像高斯模糊滤镜 | Bloom 只做了一层 blur，没有 HDR 感 | Bloom 三通道：小 blur 核心＋中 blur 光环＋大 blur 环境光，三者按 bloomStrength 加权叠加 |
| 颗粒每帧都在闪 | 荧光颗粒位置每帧换 | 颗粒位置缓存 3 秒换一次；闪烁只改亮度不改位置 |
| 蓝紫光台被门禁拦了 | deliver.py 报蓝紫占比超标 | 命令加 `--allow-blue-purple "题材是夜空/星河/梦境"`，理由写进交付说明 |
