# 沙画风格配方总表

沙画风格分四大类（新增 0 类真实写实为默认首选），每类有具体的参数配方、母题动作、签名转场和已知短板。选择时从四大类中挑一个匹配题材的，再看具体配方卡。

## 四大类选型

| 类 | 适合题材 | 光台色 | 沙色基调 | 看配方卡 |
|---|---|---|---|---|
| **0 类 真实写实沙画（参考样片同款，效果最好，默认首选）** | 一切题材：叙事、人物、风景、回忆、情感、商务、儿童、庆典…… 用户没特别指定风格就用这套 | 冷蓝青 `#005080` 透底，径向中心 `#0080A5`，边缘 `#000525` | 5 档冷灰白：`#889288` / `#A8B0A0` / `#C0C8B8` / `#D8DCD0` / `#969E8E` | `00_realistic_cool.md` |
| ① 经典暖沙台 | 叙事、人物、风景、回忆、情感类短片；第二选择（暖沙舞台款） | 暖黄 `#F5D080` 透底 | 沙金、深棕、米白三色为主 | `01_classic_warm.md` |
| ② 多彩彩沙 | 儿童、节日、庆典、童话、品牌动画；需要色彩但仍温暖 | 暖白 `#FFF4E0` 透底 | 暖红、橙黄、草绿、天青、紫金（暖色占70%） | `02_colorful_sand.md` |
| ③ 夜间荧光沙 | 夜景、星空、梦境、科幻、奇幻题材；用户明确指定「梦幻」「夜空」 | 深蓝紫 `#1A1040` 透底（需 `--allow-blue-purple "题材"`） | 荧光绿、荧光橙、荧光粉（粒子自发光） | `03_glow_night.md` |

## 沙画签名转场（不挑风格，都能用；但 s00 真实写实款默认不用程序化切）

每条转场的时长和参数在 `scripts/engine/transitions.js`：

| 转场 id | 视觉描述 | 适合 | 默认时长 |
|---|---|---|---|
| `t_pour_in` | 沙粒从上方（或手指间）倾盆而下，盖住旧画面、聚出新画面 | 开场、章节开始（s00 真实写实款用「整屏撒沙+手掌抹平」替代） | 0.55s |
| `t_finger_draw` | 一条划痕从起点划到终点，划痕后露出新画面（划痕两边有推开的沙堆） | 情节推进、揭示答案（s00 真实写实款用「指甲刮冷蓝亮线」替代） | 0.40s |
| `t_wipe_palm` | 手掌从一侧抹过，旧画面被抹平，新画面在手掌后 | 场景切换、时间流逝（s00 真实写实款用「手掌半抹+下半截留沙」替代） | 0.45s |
| `t_sand_flow` | 旧画面的沙粒像液体一样流向画面另一角，重新堆积成新画面 | 同一空间内的物体变化 | 0.60s |
| `t_scatter_wind` | 一阵风吹过，旧画面散成沙粒飞离画面，新画面在空沙台上重新汇聚 | 结尾、宏大转折 | 0.70s |
| `t_light_table` | 光台亮度从0缓慢亮起，第一幅沙画从无到有透出来 | 全片第一镜开场 | 0.80s |

## 硬要求（所有沙画风格都必须满足）

1. **光台透光感必须有**：`SAND.lightTable` 合成层。厚沙=暗色（透光少），薄沙/无沙=亮色（透光多）。手指划痕处会透出亮线，这是沙画识别度的核心。
2. **颗粒噪声层**：整幅画面叠加一层沙粒大小的噪声，强度随沙厚增加（`SAND.grain`）。没有颗粒层的就是「一张黄色图片」，不是沙画。
3. **作画痕迹**：每幅画至少保留一处「正在画」的痕迹——未完成的撒沙边缘、手指划过的推沙堆、手掌抹平的扇形区域。痕迹不要全擦干净。
4. **确定性**：所有随机数走 `seededRand(seed, t)`，同一 t 渲两次逐像素一致。
5. **光台色区间**：除③夜间荧光和 0 类真实写实外，光台色必须暖黄-暖白区间；**0 类真实写实光台色必须冷蓝青 H200~220**（绝对不许红黄暖色）。
