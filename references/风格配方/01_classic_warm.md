# 风格配方 s01 · 经典暖沙台（默认首选）

> 适用：叙事、人物、风景、回忆、情感类短片。第一眼就是「沙画」的标准风格。

## 一、色板（照抄，别自己调色）

```json
{
  "theme": "classic_warm",
  "lightTable": "#F5D080",
  "sandColors": [
    "#8B5A2B",
    "#C4915E",
    "#E8C07A",
    "#F5DEA5",
    "#A67040"
  ],
  "grainColor": "#6B4520",
  "thinSandAlpha": 0.55,
  "thickSandAlpha": 0.92
}
```

- 光台 `#F5D080`：暖黄偏金，不是纯白也不是橘黄。无沙处透出这个色。
- `sandColors[0]` 最厚最暗的沙（堆积处），`sandColors[3]` 最薄最亮的沙（边缘处）。画的时候按厚度插值。
- 颗粒噪声用 `grainColor`，比最厚的沙深一点，不是纯黑。

## 二、五层画法顺序（标杆 `scenes/s01_classic.js`）

沙画和油画相反：**沙是从光台往上铺**，先铺薄沙、再堆厚沙、最后画「擦掉」的划痕（透光处）。

1. **光台底**：整屏铺满 `lightTable`，叠一层 `SAND.tableTexture()`（非常淡的颗粒＋四周微暗角，模拟真实沙台边缘光弱）。
2. **薄沙底床**：整屏画一层半透明薄沙（`thinSandAlpha`），噪声强度0.3。这一层是「沙台上铺满了沙但还没画」的状态，不是空白。
3. **构图形状（厚沙堆积）**：按构图把要「暗」的地方（形状主体）画上厚沙（`thickSandAlpha`）。厚沙用 `SAND.dabShape`，不是纯填色——边缘要有颗粒起伏，不是光滑的几何形。
4. **细节（薄沙过渡＋划痕透光）**：用中等沙厚画出明暗层次。**最关键一步**：在形状上用 `SAND.scratchLine` 「擦」出透光的线条——这些亮线是观众识别出「手指画过」的关键，也是沙画的高光。
5. **作画痕迹层（让它活）**：加一两个「还在画」的痕迹——比如一角还在撒沙落粒、一条划痕的末端还在延伸、某处沙粒还在缓慢流动。连续运动用连续时间；颗粒位置用 10–12fps 换种子「跳动」，给手工感。

## 三、母题小循环（每段至少 2 个，从下面挑或自己写）

| id | 母题 | 代码 | 视觉 |
|---|---|---|---|
| m1 | 边角撒沙 | `SAND.pourCorner(x,y,amount,t)` | 画面一角细沙持续落下，堆成小丘，偶尔滚下几粒 |
| m2 | 细沙流动 | `SAND.flowAlong(path,speed,t)` | 沿路径有沙粒在缓慢移动，像水在沙上流过 |
| m3 | 划痕末端延伸 | `SAND.scratchGrowing(line,growth,t)` | 一条亮划痕慢慢变长，末端有被推开的沙堆 |
| m4 | 沙粒轻微跳动 | `SAND.grainJitter(area,freq,t)` | 某区域的颗粒噪声每 100ms 换一次，像沙台被轻微震动 |
| m5 | 光台呼吸 | `SAND.tableBreath(amp,freq,t)` | 光台整体亮度每 3 秒轻微起伏，像呼吸 |
| m6 | 手掌擦除残影 | `SAND.wipeTrail(shape,t)` | 形状边缘有被手掌擦过的扇形残影，慢慢消散 |

自检运动量：渲两帧（避开转场后 0.35s）做帧差，目标 3.5%–8%。低于 3% 加母题 m1 或 m2；高于 10% 减（沙画不应该像爆炸一样闪）。

## 四、签名转场（这类风格里最常用的 3 条）

- **开场**：`t_light_table`（0.8s）光台亮 → 薄沙铺 → 撒沙成第一幅。或 `t_pour_in` 直接撒沙。
- **中段切场景**：`t_wipe_palm`（0.45s）手掌从左抹到右，简单有力，符合沙画习惯。
- **揭示型情节**：`t_finger_draw`（0.4s）一条划痕「划开」旧画面露出新内容。

## 五、当前短板与避坑

| 坑 | 表现 | 修法 |
|---|---|---|
| 细线条糊了 | 写了字或画了五官，结果糊成一团看不清 | 用 s02 细沙参数；每条线至少 3px 宽；亮划痕法：用深沙画背景，然后「擦」出亮线当线条，比「用深沙直接画线条」清晰 3 倍 |
| 边缘太光滑 | 形状边缘是完美曲线，像矢量图，不像沙画 | 每个形状边缘加 `SAND.roughEdge(shape, amp=颗粒大小×2)`；不要用原生 canvas 形状直接 fill，先过 roughEdge |
| 没有透光感 | 整幅画明暗对比弱，看不出哪里沙厚哪里沙薄 | 强制：形状主体必须是 `sandColors[0]`（最暗），划痕处必须回到 `lightTable`（最亮），亮暗反差拉满 |
| 颗粒感像噪点滤镜 | 颗粒只叠加在最上层，不随沙厚变化 | 用 `SAND.grain`（`sand_paint.js`）：颗粒数量和颜色随局部沙厚变化，薄沙处少且浅、厚沙处多且深 |
| 整屏都在跳 | 颗粒每帧都换，画面闪 | 颗粒缓存：沙层颗粒位置 12fps 换一次，不是 30/60fps；光台底纹完全静态，不换种子 |
| 手掌抹除很假 | 手掌就是一个矩形擦除，没有被推动的沙 | `t_wipe_palm` 实现：擦除路径两侧各堆一条「被推出来的沙垄」，垄也要有颗粒和厚度，不是空的 |

## 六、硬要求验收（交付前对一遍）

- [ ] 光台 `#F5D080`，无沙处（如划痕）能看见这个色透出
- [ ] 颗粒层随沙厚变化，不是一张统一噪点图
- [ ] 至少 2 个母题小循环在动
- [ ] 形状边缘过了 roughEdge，没有完美几何边
- [ ] 同一 t 渲两次逐像素一致（`qa.py --determinism` 会查）
