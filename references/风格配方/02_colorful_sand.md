# 风格配方 s04 · 多彩彩沙·分层叠色

> 适用：儿童、节日、庆典、童话、品牌动画。沙是彩色的，但暖色仍占 70%，拒绝霓虹七彩拼盘。

## 一、色板（暖色 70%、冷色 30%）

```json
{
  "theme": "colorful_layered",
  "lightTable": "#FFF4E0",
  "sandColors": [
    { "layer": 0, "color": "#D9634A", "name": "朱红", "pct": 20 },
    { "layer": 1, "color": "#E8943A", "name": "橙黄", "pct": 25 },
    { "layer": 2, "color": "#E8C64A", "name": "金黄", "pct": 25 },
    { "layer": 3, "color": "#7FB08A", "name": "草绿", "pct": 15 },
    { "layer": 4, "color": "#6FA8C4", "name": "天青", "pct": 10 },
    { "layer": 5, "color": "#9B6FA8", "name": "紫金", "pct": 5 }
  ],
  "grainColor": "#4A3520",
  "layerBlend": "multiply",
  "interLayerBlur": 0.6
}
```

- 光台用暖白 `#FFF4E0`，不是纯白，避免彩色沙显得太艳。
- 每层有铺色百分比，总和 100%。撒沙时按这个比例从不同角落撒入。
- 层之间用 `multiply` 叠加＋轻微模糊，融合自然，不像色块拼盘。
- 颗粒层统一用深棕 `#4A3520`，压住彩色不飘。

## 二、六层画法顺序（标杆 `scenes/s04_colorful_layered.js`）

多彩沙的核心是**分层铺、按区域 clip、融合时只在边界处混色**，中间层不混才不会脏。

1. **光台底**：`#FFF4E0` ＋ `SAND.tableTexture()`。
2. **细沙底床（无色）**：薄米白沙一层，确保画面有「有沙」的质感，不是白底写字。
3. **逐层铺沙（从冷到暖，底层→顶层）**：
   - 每层只画自己的形状区域，用 `ctx.save() → clip(shape) → SAND.fillLayer(layer) → ctx.restore()`
   - 每层铺完叠一次 `interLayerBlur` 0.6px 柔边
   - 顺序：先铺天青（最底层，背景用）→ 草绿 → 紫金 → 金黄 → 橙黄 → 朱红（最顶层，前景主体用）
4. **融合区处理**：层与层的交界线宽 12–20px，在这个窄条里把两层按 50% 混＋颗粒抖动。**融合只在交界带做，大面积不混，混了画面会脏成褐色。**
5. **划痕透光（最亮用暖白光台）**：无论哪层的划痕，划痕最亮处回到 `lightTable` 暖白，不是该层的亮色——这样划痕的亮是一致的，不会一层红亮一层绿亮。
6. **作画痕迹层**：从朱红/橙黄（暖色层）挑一两个角落在撒沙落粒；可选 m7 彩沙瀑布（一条细流从上方倾倒，颜色渐变）。

## 三、母题小循环

| id | 母题 | 视觉 |
|---|---|---|
| m1 | 边角撒沙（某色） | 画面一角某色的细沙持续落 |
| m7 | 彩沙瀑布 | 一条 30px 宽的沙流从顶部倾泻，颜色沿流程从朱红渐变到天青，流到底部堆积成彩虹丘 |
| m8 | 层边缘微流动 | 两层交界的融合带每秒有±2px的缓慢推进，像潮沙线 |
| m3 | 划痕末端延伸（某色） | 一条彩线慢慢变长 |
| m5 | 光台呼吸 | 同暖沙版 |

## 四、签名转场

- **开场**：`t_rainbow_pour`（0.9s）彩沙瀑布从上到下撒，彩虹般铺满沙台成第一幅。
- **中段**：`t_layer_shift`（0.5s）彩色层以不同速度横向移，错位后重新对齐成新画面。
- **结尾**：`t_melt_to_rainbow`（0.7s）所有颜色的沙向画面中心流、融合成一束彩虹瀑布流走。

## 五、短板与避坑

| 坑 | 表现 | 修法 |
|---|---|---|
| 画面脏成一锅粥 | 层大面积混色，整体变成脏褐色 | 严格 clip，每层只在自己的区域；融合带≤20px；暖色层在上、冷色层在下（冷色被暖色压住不会泛脏） |
| 彩沙太艳像塑料 | 颜色饱和度太高，像彩色橡皮泥 | 每色加 15% 的棕灰调；颗粒层用深棕全局压一遍；光台暖白不是纯白 |
| 冷色太突出 | 天青/紫金跳出来抢戏 | 冷色层铺色 pct≤25% 总和；冷色只在背景区，前景主体用暖色系 |
| 转场层断层 | 转场时各层不同步，能看见「三明治」分开了 | 转场函数一次操作所有层的离屏画布，不是每层单独转 |
