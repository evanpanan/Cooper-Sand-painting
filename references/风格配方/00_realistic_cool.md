## 一、色板（照抄，别自己调色）

```json
{
  "theme": "realistic_cool",
  "lightTable": "#0080A5",
  "sandColors": [
    "#889288",
    "#A8B0A0",
    "#C0C8B8",
    "#D8DCD0",
    "#969E8E"
  ],
  "grainColor": "#606858",
  "thinSandAlpha": 0.50,
  "thickSandAlpha": 0.90
}
```

- 光台主底 `#005080` 深蓝青；径向暗角中心 `#0080A5`，暗角边缘 `#000525`。无沙处透出的光色是 `(R≈0, G≈90, B≈145) ± 20`。不是暖黄，绝对不能带红黄。
- `sandColors[0]` thickest 最厚最暗的沙 `#889288` 暗灰沙，`sandColors[4]` 暗边冷棕灰 `#969E8E`。画的时候按厚度插值。
- 颗粒色 `#606858` 冷灰，比厚沙深约 20%。不是纯黑。
- thinAlpha=0.50, thickAlpha=0.90。薄沙半透明，厚沙接近不透明。

## 二、六层画法顺序（标杆 scenes/s01_classic.js 改色版）

沙画和油画相反：**沙是从光台往上铺**，先铺薄沙、再堆厚沙、最后画「擦掉」的划痕（透光处）。

1. **光台底**：整屏铺满光台径向渐变（中心 `#0080A5` → 主体 `#005080` → 边缘 `#000525`），叠一层 `SAND.tableTexture()`（非常淡的冷灰颗粒＋四周微暗角，模拟真实沙台边缘光弱）。光台呼吸幅度 amp=0.02（2%，比暖沙款大一点）。
2. **薄沙底床**：整屏画一层半透明薄沙（alpha=0.50），冷灰 `#C0C8B8` 系，噪声强度 0.3。这一层是「沙台上铺满了沙但还没画」的状态，不是空白。颗粒量比暖沙款少 10%（冷光台下更容易看到）。
3. **构图形状（厚沙堆积）**：按构图把要「暗」的地方（形状主体）画上厚沙（alpha=0.90）。厚沙用 `SAND.dabShape`，不是纯填色——边缘要有颗粒起伏，不是光滑的几何形。厚沙颜色从 `#889288`（最暗）→`#A8B0A0`→`#C0C8B8` 按厚度插值。
4. **细节（薄沙过渡＋划痕透光）**：用中等沙厚画出明暗层次。**最关键一步**：在形状上用 `SAND.scratchLine` 「擦」出透光的线条——这些亮线是光台中心色 `#0080A5`（冷蓝青），不是暖黄。冷蓝亮线在冷灰沙上识别度比暖黄划痕高 2 倍。
5. **暗边层**：形状轮廓最外缘叠一层冷棕灰 `#969E8E` 暗边，宽度≈1–2px，增加立体感。这层比暖沙款更明显。
6. **作画痕迹层（让它活）**：加一两个「还在画」的痕迹——比如一角还在撒沙落粒、一条划痕的末端还在延伸、某处沙粒还在缓慢流动。连续运动用连续时间；颗粒位置用 11fps 换种子「跳动」，给手工感。不要全擦干净，保留半铺半未铺过渡区。

## 三、母题小循环（每段至少 2 个，从下面挑或自己写）

| id | 母题 | 代码 | 视觉 |
|---|---|---|---|
| m1 | 边角撒沙（冷灰版） | `SAND.pourCorner(x,y,amount,t)` | 画面一角细沙持续落下，堆成小丘，偶尔滚下几粒。沙粒冷灰 `#C0C8B8`~`#889288` |
| m2 | 细沙流动 | `SAND.flowAlong(path,speed,t)` | 沿路径有沙粒在缓慢移动，像水在沙上流过。冷光台下沙粒明显，速度稍慢 0.8× |
| m3 | 划痕末端延伸 | `SAND.scratchGrowing(line,growth,t)` | 一条冷蓝亮划痕慢慢变长，末端有被推开的沙堆。亮线色 `#0080A5` |
| m4 | 沙粒轻微跳动 | `SAND.grainJitter(area,freq,t)` | 某区域的颗粒噪声每 11fps 换一次，像沙台被轻微震动。颗粒量 -10% |
| m5 | 光台呼吸（冷光版） | `SAND.tableBreath(amp=0.02,freq=0.5,t)` | 光台整体亮度每 3 秒轻微起伏 2%，像呼吸。暖沙是 1.5%，冷光更明显 |
| m6 | 手掌擦除残影（半抹） | `SAND.wipeTrail(shape,t)` | 形状边缘有被手掌擦过的扇形残影，慢慢消散。半抹=保留下半部、擦掉上半部，不是全抹 |

自检运动量：渲两帧（避开转场后 0.35s）做帧差，目标 3.5%–8%。低于 3% 加母题 m1 或 m2；高于 10% 减（沙画不应该像爆炸一样闪）。真实样片底部前缘 10% 高度运动>15%（手一直在下缘），顶部<3%，作画区 5~9%。

## 四、签名转场（这类风格里最常用的 3 条）

- **开场**：整屏撒沙（从手指间一点倾出）0.8s → 手掌横向抹平 0.4s → 第一幅画出。不用程序化 `t_pour_in`，完全模拟真实手的动作。或 `t_light_table`（0.8s）光台亮→薄沙铺→撒沙。
- **中段切场景**：手掌半抹（不是全抹！），下半截留沙、上半截重画，0.8s。符合真实样片的 6 次完整场景循环方式。不用程序化 `t_wipe_palm` 硬切。
- **揭示型情节**：指甲刮出冷蓝亮线（`#0080A5`），一条亮划痕「划开」旧画面露出新内容。冷蓝亮线在冷灰沙上识别度比暖黄高 2 倍。划痕两边有被推开的冷灰沙堆。

## 五、当前短板与避坑（冷光台不暖款）

| 坑 | 表现 | 修法 |
|---|---|---|
| 暖黄偏色 | 光台或沙粒不小心混入了红黄暖色，哪怕一点点，像假的 | 色板硬约束：光台 H=200~220，沙粒 H=80~110。调色后跑 `qa.py --palette-check` 验 HSL |
| 冷沙写成金沙 | 沙粒被写成 `#F5DEA5` 之类的金黄暖色调 | 沙粒色必须从 5 档冷灰选：`#889288`/`#A8B0A0`/`#C0C8B8`/`#D8DCD0`/`#969E8E` |
| 光台呼吸幅度写 1.5% | 冷光台下 1.5% 呼吸几乎看不见，画面死气 | 冷光台款呼吸幅度 amp=0.02（2%），暖沙是 1.5%。冷光需要更大幅度才看得见 |
| 高光划痕写暖黄 | 划痕透出暖黄亮线，和冷灰沙对比弱、识别度低 | 划痕亮线=光台中心 `#0080A5`（冷蓝青），冷蓝亮线比暖黄划痕识别度高 2 倍 |
| 颗粒量和暖沙一样 | 冷光台下沙粒更容易被眼看到，颗粒一样多会显得画面「脏」「乱」 | 颗粒量 -10%（grain 函数 count×0.9）。颗粒换种 11fps 不变，但总数少一点 |
| 细线条糊了 | 写了字或画了五官，结果糊成一团看不清 | 每条线至少 3px 宽；亮划痕法：用深沙 `#889288` 画背景，然后「擦」出冷蓝亮线 `#0080A5` 当线条，比「用深沙直接画线条」清晰 3 倍 |
| 边缘太光滑 | 形状边缘是完美曲线，像矢量图，不像沙画 | 每个形状边缘加 `SAND.roughEdge(shape, amp=颗粒大小×2)`；不要用原生 canvas 形状直接 fill，先过 roughEdge |
| 没有透光感 | 整幅画明暗对比弱，看不出哪里沙厚哪里沙薄 | 强制：形状主体必须是 `sandColors[0]`=`#889288`（最暗），划痕处必须回到光台中心 `#0080A5`（最亮），亮暗反差拉满 |
| 颗粒感像噪点滤镜 | 颗粒只叠加在最上层，不随沙厚变化 | 用 `SAND.grain`（`sand_paint.js`）：颗粒数量和颜色随局部沙厚变化，薄沙处少且浅、厚沙处多且深 |
| 整屏都在跳 | 颗粒每帧都换，画面闪 | 颗粒缓存：沙层颗粒位置 11fps 换一次，不是 30/60fps；光台底纹完全静态，不换种子 |
| 手掌抹除很假（全抹） | 手掌就是一个矩形全擦除，没有被推动的沙，也没有下半截保留 | 手掌半抹实现：擦除路径只擦掉上半屏，下半屏保留旧沙；擦除路径两侧各堆一条「被推出来的沙垄」，垄也要有颗粒和厚度 |
