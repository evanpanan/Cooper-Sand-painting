# 04 · 纯代码绘制：用 Canvas 把一幅沙画画出来并让沙粒流动

> 本页主线：沙画场景和物件通过程序与沙粒渲染器实现。人和真人角色不直接用代码画进成片，方案见 10 号。

## 一、工程骨架（`scripts/engine/`，复制一份就能开新片）

```
index.html        加载顺序：lib/fonts → lib/util → lib/sand_paint → eras → transitions → scenes/index → engine
eras.js           段落表：id、占几个八分音符(eighths)、转场{type,dur,delay,cx,cy}、沙画角标样式
scenes/<id>.js    每段一个文件：SCENES['<id>'] = { draw(c, lt, t) }  ← 主要工作量在这里
transitions.js    沙画签名转场库：(c, A旧, B新, p, o) → 画一帧；都带光台微闪
engine.js         节拍网格→各段 t0/t1；转场时新旧两段各画进离屏再交给转场；拍点镜头冲击
lib/sand_paint.js 沙画核心库：颗粒渲染器、透光层合成、作画路径辅助、撒沙/抹平/流动/飘散实现
lib/util.js       Path2D 辅助、seededRand、坐标工具、离屏 canvas 管理
render.py         无头 Chromium 逐帧调 renderFrame(t) → PNG 管道 → ffmpeg 出片；--solo/--stills/--spec
```

渲染速度参考：15 秒 30fps 整片约 60 秒（M 系列 Mac）。单段每帧大多 5–30ms；最重的彩沙分层+飘散转场 90ms/帧。

## 二、一个沙画场景怎么画（六层，标杆 `scenes/s01_classic.js`）

> 六层是经典暖沙的默认顺序。彩沙/荧光沙有自己的版本，见 `风格配方/` 里对应的配方卡。

1. **光台底**：整屏 `lightTable` ＋ `SAND.tableTexture()`（淡颗粒＋四角暗角）。永远最底层，后面所有层都叠在它上面。
2. **薄沙底床**：半透明薄沙整屏铺一层（`thinSandAlpha`），颗粒强度 0.3。这一步让「空沙台」不是空白而是有沙的，后面所有作画都在这个基础上加/减沙。
3. **构图主体（厚沙堆积）**：按构图把形状主体用 `SAND.dabShape()` 画上厚沙（`thickSandAlpha`）。**不要直接 fill 一个 Path2D**。`dabShape` 会做：
   - `roughEdge(shape)` 把光滑几何边变成沙画特有的起伏边缘
   - 按 `sandColors[0..3]` 做厚度插值（中心厚→边缘薄）
   - 形状内部加颗粒（颗粒密度是沙厚的函数）
4. **细节层次（中沙过渡）**：在厚沙形状上用中等沙厚画明暗过渡。不要一条亮线一条亮线硬画，先用沙厚画出整体体积。
5. **划痕透光（亮线／亮区）**：用 `SAND.scratchLine()` / `SAND.scratchArea()` 「擦掉」沙，露出底下的光台。这一步是**最关键的沙画识别点**：亮的划痕代表手划过去的地方，画面从此「真的是沙画」。
6. **作画痕迹层（让它活）**：加 1–2 个母题循环（`风格配方/01_classic_warm.md` 表 m1–m6），画面从此「真的在画」不是一张沙画图片。

## 三、沙画画法库速查（都在 `lib/sand_paint.js`）

| 函数 | 用途 | 关键参数 |
|---|---|---|
| `SAND.lightTable(c, palette)` | 第 1 层：画光台底 | palette.lightTable 色、暗角强度 |
| `SAND.thinBed(c, palette, alpha)` | 第 2 层：薄沙整床铺 | alpha=0.45–0.6；颗粒数随 alpha 线性 |
| `SAND.dabShape(c, palette, path, mode)` | 第 3 层：按形状堆沙 | mode: 'thick'/'medium'/'thin'；内部自动 roughEdge |
| `SAND.roughEdge(path, amp)` | 给 Path2D 加沙粒起伏边 | amp≈颗粒大小×2；路径长的话 amp 按比例调 |
| `SAND.scratchLine(c, palette, p0, p1, width)` | 第 5 层：划一条亮线 | width 3–8px；划痕两侧自动堆「被推出去的沙垄」 |
| `SAND.scratchArea(c, palette, path, depth)` | 第 5 层：刮掉一块区露光台 | depth=1 全刮回光台；0.5 刮一半 |
| `SAND.grain(c, area, thicknessMap)` | 颗粒层（所有沙层自动调用，一般不用手动） | thicknessMap(x,y) 返回局部沙厚，颗粒密度随它变 |
| `SAND.pour(c, palette, x, y, amount, t)` | 母题：从(x,y)撒 amount 比例的沙 | t 是全局时间，0–1 完整撒一次；落沙有抛物线轨迹 |
| `SAND.pourCorner(c, palette, x, y, amount, t)` | 母题：从角落持续撒沙 | x,y 角落点；amount 每 0.1 秒落多少粒 |
| `SAND.flowAlong(c, palette, path, speed, t)` | 母题：沙粒沿路径流动 | speed 像素/秒；颗粒走路径弧长参数 |
| `SAND.scratchGrowing(c, pal, p0, p1, growth, t)` | 母题：亮划痕末端延伸 | growth 0–1，t 时显示前 growth×总长的部分 |
| `SAND.wipeTrail(c, pal, path, width, t)` | 母题：手掌擦除的扇形残影 | 宽度递减＋颗粒逐渐稀疏 |
| `SAND.glow(c, pos, color, intensity, blur)` | 荧光沙专用：画自发光颗粒 | intensity 0.5–1.2；三通道 bloom（3.5/1.5/0.5px blur） |
| `SAND.fillLayer(c, layerDesc, mask)` | 彩沙专用：按层描述铺一层沙 | mask 是 clip path；层间自动 0.6px blur |
| `SAND.composite(c, layers)` | 彩沙专用：多层合成＋交界带融合 | layers 按从下到上顺序 |

## 四、让沙「活」：动作清单与量法

- 每段至少：1 个沙画作画过程（撒沙成形/划痕延伸/抹平残影）＋ 2–4 个母题小循环。短段 <0.5s 节奏要快到 15fps 步进。
- 自检运动量：渲两帧（避开转场后 0.35s 的镜头冲击）做帧差。沙画目标 **3.5%–8%**：
  - <3% ＝太静，加 m1(撒沙) 或 m2(流动)
  - 3–6% ＝正常
  - 6–8% ＝活泼（适合叙事高潮）
  - >8% ＝太跳，减颗粒换种频率（降到 8fps 换一次）或减同时在动的母题数
- 动的东西要在视线焦点上：主角形状、主划痕、主撒沙点。边角的微动只是气氛，不算真正的运动。

## 五、踩过的坑

- **合成模式 `destination-out` 在段画布上用会挖洞**，进视频是黑的。所有「刮掉沙」的操作（scratchLine、scratchArea、wipe）都在沙层离屏内部做，最后 drawImage 贴回去。
- **划痕两侧没堆沙垄**，出来就是光滑的亮条，很假。`scratchLine` 默认已经堆垄，如果你自己手动画亮线一定要加。
- **颗粒位置每帧换 = 画面闪**。颗粒缓存：`lib/sand_paint.js` 里 `SAND._grainCache` 按 10–12fps 过期，同一过期窗口内颗粒位置逐像素一致。
- **`putImageData` 直接写到目标 canvas** 会绕过 engine 的镜头冲击和转场裁剪。先写离屏，再 drawImage。
- **读像素的离屏 context** 用 `{willReadFrequently:true}`；每帧用 `g.reset()` 或手动 save/restore，不然后面 lineJoin/透明度残留。
- **光台暗角太大**，观众会读成「显示器的问题」不是「沙台边缘光弱」。暗角范围控制在画面外 8% 以内，最大降亮度 ≤12%。
- **厚沙直接 fill 一个 Path2D**，出来像巧克力块。必须 `dabShape` 过 roughEdge 加颗粒起伏。
- **一道划痕从左划到右全程均匀亮**，很像 UI 下划线不是手划的。`scratchGrowing` 加：起始端稍暗、末端有沙堆、中间最亮。
- **确定性**：所有随机用 `seededRand(seed, t, x, y)`，同一个 (t,x,y) 永远出同样数。`qa.py --determinism` 会在 3 个 t 上各渲两次查逐像素一致。
