# 角色精细度：沙画里的人要做到哪一档

> 写镜头表之前先把全片所有有人的镜列出来，按每镜的「脸有多清楚、要表现什么」分到 F0–F4 五档。选方案 A/B/C（`10-角色.md`），然后整支片按这个档执行，不要到代码写一半了临时升档/降档。

## 五档定义 + 沙画专属规则

| 档 | 镜头里人的大小和视角 | 要表现的内容 | 允许方案 | 沙画专属硬约束 |
|---|---|---|---|---|
| **F0 · 无角色** | 没有人 | — | 不用做角色 | — |
| **F1 · 只出手 / 背影远** | 人占画面高度 ≤ 25%；只看得到手（正在划沙）或背影远远站着；完全看不到脸 | 「那个在沙上画画的人」存在即可，不传达身份/情绪 | **B 纯代码剪影**（`SAND.SIL.*`） | 绝对不要加正脸/五官。手的剪影不要画手指细节（5 根手指看得到就行，不画指甲/关节） |
| **F2 · 侧影 / 中远景** | 人占画面 25%–50%；侧影/半侧影，或剪影中景；五官完全不可辨（剪影）或只能看出大致轮廓 | 传达「某个人物的姿态」，不传达表情；观众不一定认得出是谁 | **B 纯代码剪影升级版**（path 更复杂，姿态写进 scene） | 可以加衣服的沙画分层（厚沙=外套、中沙=衬衣）；绝对不加人脸五官细节；头发用沙厚过渡不要发丝线条 |
| **F3 · 中景正脸** | 人占画面 50%–70%；正面/微侧；脸要看得出来是「那个人」（Cooper 不是路人甲）；表情只需要做到「微笑/严肃/惊讶」三选一，不需要精细 | 传达具体人物、大致情绪 | **A 方案（AI 生帧→沙化合成） or C（帧库）** | 人脸必须用 A 或 C，**绝对不准代码手画五官**。肩以上可以用沙化，肩以下可以继续用 B 方案剪影省算力。F3 是最低要求正脸档，需要至少 5 张候选挑 1 张。 |
| **F4 · 特写 + 表情变** | 人占画面 ≥ 70%；脸部特写；需要表现喜怒哀乐精细表情（笑的鱼尾纹、惊讶的张嘴等）；表情有 3 种以上变化 | 人物情绪表演、角色特写镜头 | **A 方案帧序列 or C 方案帧库** | 需要至少：5 种表情 × 每种 3 张候选 = 15 张生帧挑 5 张；每种表情之间做 5 帧 dissolve（0.15s 过渡）不要硬切；沙化滤镜 `gamma_thickness` 调到 1.1（人脸要薄一点才读得出五官） |

## 全片档位一致性

同一支片里不同镜可以不同档（远景 F1 + 切近景 F3 = OK），但：
1. **同一个人物在不同镜头的沙化参数要一致**。不能远景是深棕沙、近景突然变成金色沙。
2. **升档时不能跳档**。前一镜是 F1（远背影），下一镜突然 F4（脸特写）会很突兀。中间加一镜 F2（中景侧影）过渡。
3. **同一镜里出现两个人物时按更高的那档**。比如镜里有 F1 背影 + F3 正脸（两个人），这一镜的方案允许 A 用于 F3 人物、B 用于 F1 人物（可以混用）。

## 快速判档表（拿不准时用）

| 你想问的 | 答 | → 档 |
|---|---|---|
| 「画面里只有一只手在划沙」 | 是 | F1 |
| 「这个人只看得到背面/侧面，看不到脸」 | 是 | F1/F2 |
| 「我想让观众认出这是 Cooper」 | 是 | ≥F3 |
| 「要表现 Cooper 在笑/哭/惊讶」 | 是 | ≥F4 |
| 「我现在没有 AI 生图工具」 | 是 | ≤F2 |
| 「观众不需要认出是谁，只要传达『有一个人在』」 | 是 | F1（别加额外细节） |
| 「要做吉祥物/拟人角色（不是真人）」 | 是 | 可以 C 方案帧库，允许比真人低一档；但仍然禁止手画 Q 版五官（AI 生了沙化 or 纯剪影） |

## 沙画人物的绝对禁止清单（违者红灯）

1. ❌ 禁止代码手画人脸五官：眼睛/瞳孔/鼻子/嘴巴/睫毛/眉毛，用代码一条线一条线画出来的通通算。
2. ❌ 禁止用 Q 版/简化版/卡通版小人代替真人。沙画里没有「简化人设」这档——要么剪影（无脸），要么正脸（AI 生→沙化），中间档不存在。
3. ❌ 禁止给沙画里的非人物体加脸（沙画的太阳、金币、小球、数字，不准有眼睛和笑嘴）。这是 AI slop 经典特征。
4. ❌ 禁止 F3/F4 级人物放在小于画面 40% 高度的区域。放这么小沙化后人脸会糊成一团，等于白做；要么放大要么降档做剪影。
5. ❌ 禁止用深棕/黑色直接填眼睛、用粉色填嘴巴。人脸所有细节必须来自「沙厚差异＋光台透光」，不是用不同色沙画五官——真实沙台上你不可能换颜色的沙来画眼睛，所以代码里也不能这么做。

## 沙画拟物主角例外（仅限非真人的吉祥物）

如果你的角色是**非真人的吉祥物/拟物角色（比如一个有形象的品牌 IP）**，且你有这个 IP 的官方矢量图/设计稿，可以手写沙画版的正脸，但要满足：
- 这个 IP 的官方设定本身就是「简单形状」（不是半写实卡通人）
- 手写的沙画版完全按 IP 官方形状的比例，没有自己发明五官位置
- 沙画版：所有线条用划痕亮线，所有填充用厚沙堆积；颗粒/roughEdge/透光照常走
- 最终效果和官方形象放在一起对比，一眼认得出是同一角色

真人角色不适用这个例外，只能 A/C 方案。
