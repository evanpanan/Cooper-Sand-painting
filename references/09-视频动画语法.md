# 09 · 沙画动画语法：JSON 驱动的参数化片段，按口播帧精确出片

> 适用于：做解说/财经/故事/科技类的沙画动画段；口播管线要一段精确到帧的沙画片段；第一次做沙画没信心写 scene。
>
> 和 `04-纯代码绘制.md` 的 scenes 路线是二选一：简单片段用这里的 JSON spec + render.py --spec，复杂画面用 scenes 手写。

## 一、先选型：8 种沙画语法（按你的内容选）

| id | 语法名 | 视觉 | 适合题材 | 单段推荐时长 | 示例 spec 文件 |
|---|---|---|---|---|---|
| y1 | 白板手划型 | 一只手（沙画手剪影）在沙台上从左划到右，划出一条叙事线；沿线每一段出一个图标+一行字 | 时间线、步骤型讲解、产品功能介绍 | 4–8s | `examples/y1_whiteboard_hand.json` |
| y2 | 撒沙揭示型 | 沙粒从上方洒满沙台，慢慢「落出」一幅完整画面＋大字；撒完留几秒呼吸 | 开场标题、章节开头、金句卡 | 3–6s | `examples/y2_pour_reveal.json` |
| y3 | 手掌抹平切换型 | 一个手掌（沙画剪影）从左抹过，抹完露出下一个要点；要点是图＋字；一要点一抹 | 要点列表、对比、列项（≤5 项） | 每项 1.5–2s，总 ≤8s | `examples/y3_palm_wipe_list.json` |
| y4 | 沙粒流动聚合型 | 零散沙粒从四面八方流向画面中心，聚合成一个物件/人像/数字；聚完停一下 | 关键数字、核心物件、主题揭晓 | 4–7s | `examples/y4_flow_gather.json` |
| y5 | 多层对比型 | 沙台从中间竖线一分为二，左右两边用不同沙色/不同沙厚画两个对比项；每边自己的字 | A vs B、前 vs 后、利 vs 弊 | 4–8s | `examples/y5_split_compare.json` |
| y6 | 划词高亮型 | 一整段厚沙铺满沙台当「草稿」，然后用划痕一行行「划亮」句子；每行亮 2 秒换下一行 | 诗句、名言、引述、关键段落文字 | 每句 2s，总 ≤8s | `examples/y6_line_highlight.json` |
| y7 | 财经图表型 | 沙堆成坐标轴（划痕亮线），然后柱状图/折线图慢慢「堆起来」（沙从底部堆）；数字卡节拍点出现 | 数据讲解、趋势、季度报表 | 6–8s（图4s＋数字2–4s） | `examples/y7_finance_chart.json` |
| y8 | 发布会金句型 | 一个主关键词从沙粒聚合＋缩放砸入，下面一行小字；背景光台缓慢呼吸，沙粒边角微动 | 主题句、口号、slogan、章节标题 | 3–5s | `examples/y8_keynote_bigtype.json` |

选型原则：
- 解说逻辑是「步骤」→ y1 白板手划
- 解说逻辑是「要点列表」→ y3 手掌切换
- 解说逻辑是「一个数字或物件最关键」→ y4 流动聚合 / y8 发布会
- 解说逻辑是「文字很重要」→ y6 划词高亮
- 解说逻辑是「数据」→ y7 财经图表
- 开场/章节头 → y2 撒沙揭示
- 对比类 → y5 多层对比

## 二、起手必查（写 spec 前先把这两行锁好）

每一个 spec 的开头**必填**：

```json
{
  "theme": "classic_warm",
  "palette_file": "../references/色板.md",
  "palette_name": "暖沙标准-5 色",
  "duration": 5.5,
  "fps": 30,
  "resolution": [1920, 1080]
}
```

- `theme`：只能三选一 `classic_warm` / `colorful` / `glow_night`（`风格配方/INDEX.md` 的三大类）。选错了色和光台都会错。
- `palette_name`：`色板.md` 里的其中一套名。**全片所有片段的 `theme`＋`palette_name` 必须是同一个**（窄桥「一套画风」的实现）。
- `duration`：精确到小数点后 1 位。口播管线对接时要和口播的实际时间严丝合缝。渲染会按 duration 精确裁。

然后选一个语法 id，把它的「必填字段」全填上：

```json
{
  "grammar": "y4_flow_gather",
  "y4": {
    "target_shape": "circle_at_960_540_r_200",
    "layers": [
      { "sandColorIdx": 0, "flowFrom": "left" },
      { "sandColorIdx": 1, "flowFrom": "top" },
      { "sandColorIdx": 2, "flowFrom": "right" }
    ],
    "gatherEndAt": 0.7,
    "text": {
      "main": "3亿",
      "pos": [960, 540],
      "size": 180,
      "appearedAt": 0.75
    }
  }
}
```

每个语法的必填字段和可选字段，看对应的语法卡：`references/沙画语法/y4_flow_gather.md`。

## 三、渲染

```sh
# 单片段
uv run --with playwright python 代码工程/render.py --spec 片段.json --out 渲染/片段.mp4

# 单片段出静帧（验收用）
uv run --with playwright python 代码工程/render.py --spec 片段.json --stills 0,0.3,0.6,1.0 --out 渲染/片段帧

# 质量门
uv run scripts/qa.py --spec 片段.json --out 渲染/qa_片段
```

**单个参数化片段最长 8 秒。** 超过 8 秒一定要拆成两个片段，再 ffmpeg concat。因为语法的内部时间线（撒沙→停→转场下一状态）设计的最大周期是 8s，再长会重复，观众读成「循环动画」。

## 四、8 种语法的 JSON 字段速查

> 完整字段和默认值看 `references/沙画语法/y*.md`。这里只列「有默认值可以不写」和「必须写」的区别。

### y1 白板手划
```json
"y1": {
  "segments": [                 // 必写，每段一步
    { "t_start": 0.0, "t_end": 1.2,
      "from": [200, 540], "to": [600, 540],
      "icon": "calendar",      // 支持的图标名见语法卡
      "text": "2023 起步",      // 屏上字 ≤8 字
      "text_pos": [600, 470] }
  ],
  "hand_style": "dark_silhouette",  // 可选，默认这个
  "line_width_px": 6               // 可选，默认 6
}
```

### y2 撒沙揭示
```json
"y2": {
  "pour_from": "top",           // 必写：top / bottom-left / all
  "pour_endAt": 0.6,            // 必写，撒沙结束秒数
  "reveal_target": "scene:s01", // 或直接内嵌 shape；必写
  "title": {
    "main": "Cooper 的故事",
    "sub": "2018 – 2026",
    "main_size": 160,
    "sub_size": 48,
    "pos": [960, 540],
    "revealAt": 0.7
  }
}
```

### y3 手掌抹平列表
```json
"y3": {
  "items": [                    // 必写，≤5 项
    { "title": "第一件事",
      "icon": "rocket",
      "t_start": 0.0,
      "t_dwell": 1.5 },         // 停多久
    { "title": "第二件事", "icon": "chart",  "t_start": 1.5, "t_dwell": 1.5 }
  ],
  "wipe_direction": "left_to_right",  // 可选，默认
  "layout": "center_stack"             // 可选
}
```

### y4 流动聚合
```json
"y4": {
  "target_shape": "path:...",         // 必写：支持 circle_at_x_y_r / rect_... / path_SVG_D_string
  "layers": [                         // 必写
    { "sandColorIdx": 0, "flowFrom": "left",  "delayPct": 0.0 },
    { "sandColorIdx": 1, "flowFrom": "right", "delayPct": 0.1 }
  ],
  "gatherEndAt": 0.7,
  "text": { "main": "...", "size": 160, "pos": [960,540], "appearedAt": 0.75 }
}
```

### y5 多层对比
```json
"y5": {
  "split_px_x": 960,                // 中线 x，默认宽/2
  "left": {
    "sandColorIdx": 0,
    "title": "前",
    "body": ["300 用户", "1 条线"],
    "icon": "old_tv",
    "doodle": "before_sketch"
  },
  "right": {
    "sandColorIdx": 1,
    "title": "后",
    "body": ["3 亿用户", "50 条线"],
    "icon": "rocket",
    "doodle": "after_sketch"
  },
  "reveal_order": "together"        // together / left_then_right
}
```

### y6 划词高亮
```json
"y6": {
  "base_text": [               // 必写，整段文字
    "黄河之水天上来，",
    "奔流到海不复回。"
  ],
  "highlight_lines": [         // 必写，逐行划亮时间
    { "line_idx": 0, "t_start": 0.5, "duration": 1.8 },
    { "line_idx": 1, "t_start": 2.5, "duration": 1.8 }
  ],
  "font_size": 64,
  "align": "center"
}
```

### y7 财经图表
```json
"y7": {
  "chart_type": "bar" | "line" | "donut",
  "axis": {
    "x_labels": ["Q1", "Q2", "Q3", "Q4"],
    "y_max": 100,
    "y_step": 20
  },
  "data": [30, 45, 60, 88],       // 必写，长度＝x_labels
  "data_appear_order": "sync" | "one_by_one",
  "callouts": [
    { "idx": 3, "label": "历史新高", "t": 5.0 }
  ],
  "total_number": { "text": "总营收 2.23 亿", "appearedAt": 6.5 }
}
```

### y8 发布会金句
```json
"y8": {
  "main_word": "长期主义",
  "main_size": 240,
  "sub_word": "做时间的朋友",
  "sub_size": 56,
  "slam_t": 0.5,                 // 砸入到达时间；0.3~0.8 推荐
  "slam_scale": 1.55,            // 砸入缩放峰值
  "dwell_breath": true           // 停住后光台呼吸
}
```

## 五、踩过的坑

- **屏上字比 8 字多**，一行塞不下挤在一起看不清。语法 y1/y3/y4/y8 的屏上字**强制 ≤8 字**，lint 会查。多字的话拆成多行（用数组 `text_lines`）或拆成多段。
- **duration 精确到 0.1 都写不齐**，口播接上差 0.2 秒。写 spec 时用 `时间轴/逐句对齐.json` 里的数值，**直接拷贝**，不要口算。
- **全片所有片段的 theme/palette 没对齐**，接起来每一镜换一套色＝PPT 拼盘。写第一个 spec 的时候把 theme/palette_name 抄下来，后面所有片段从第一个复制粘贴。lint 查一致性。
- **y7 财经图表的数据 `y_max` 小于 `max(data)`**，柱子堆到沙台外面被裁了。lint 会查。`y_max` 至少是 `max(data)*1.2`，留空余量。
- **y4 流动聚合的 `gatherEndAt` 写在 1.0**，导致聚完立刻结束，观众还没看清聚合的是什么。聚完至少留 duration 20% 的 dwell（比如 5s 片 gatherEndAt=0.75，最后 1.25s 停住看）。
