# 01 · 拆解：把一段参考沙画拆成「能写代码的地图」

> 适用于「复刻这个沙画」「拆一下这段」。拆完不是为了逐像素抄，是为了学它的作画机制。

## 一、跑拆解脚本

```sh
uv run scripts/analyze/breakdown.py --video <参考沙画.mp4> --out 拆解/
# 产物：
#   拆解/镜头切分.txt       每镜起止秒、该镜时长
#   拆解/转场类型.txt       每个转场的类型（撒沙/抹平/流动/飘散）和中心点
#   拆解/节拍网格.txt       128 BPM 对齐后的剪点位置（可直接填进 eras.js）
#   拆解/运动热图/          每镜 3 张：撒沙热图/划痕热图/整体运动
#   拆解/色板提取.png       从每一镜抠出的实际沙色色板（跟配方卡对照）
#   拆解/关键帧/            每秒一张 jpg，人工看结构
```

脚本做不了的（作画顺序、哪层先画），人工补进 `拆解/人工笔记.md`。

## 二、人工必查的 6 项

脚本给的是机器量出来的，下面这 6 项必须人眼看一遍、逐镜写结论：

1. **每镜的「作画顺序」**：先撒了什么？第一笔划的是哪条线？什么时候抹的？抹的手势方向（左→右 / 右→左 / 中心→四周）？
2. **透光区的位置**：哪些地方是「没沙＝亮」？是先画了厚沙然后刮掉（划痕法），还是一直没铺沙（留白法）？
3. **颗粒感的粗细**：是细沙（颗粒≈1px）、标准沙（≈2–3px）还是粗沙（≈5–8px）？不同区域用的颗粒大小一致吗？
4. **转场的真正机制**：
   - 撒沙入：沙粒是从**上方整条落下**，还是从**手指间一点倾出**？
   - 手掌抹：是「一只手的扇形扫过」还是「左右双掌合拢抹平」？被推出来的沙堆在了哪边？
   - 飘散：风从哪边来？沙粒是直线飞走还是螺旋飞走？
5. **作画痕迹保留了多少**：画面最终停住时，还能看见几条未完成的划痕？撒沙的边缘有没有半铺半未铺的过渡区？痕迹是沙画师刻意保留的，还是你感觉他擦忘了？
6. **光台亮度曲线**：整段有没有光台突然调亮/调暗（比如揭示答案时打亮一条线）？是局部亮还是全台亮？

## 三、把拆出来的东西整理成「复刻任务单」

拆完后把每一镜写成 4 行，后面直接照这个写代码：

```
镜 N (2.3s-4.1s):
  画风: s01 经典暖沙
  顺序: ① t=2.3 光台亮 → ② t=2.5 从右上角撒沙铺床 0.5s → ③ t=3.0 手指从中央划出人脸轮廓 0.8s → ④ t=3.8 眼窝两条亮划痕
  转场(到下一镜): t_wipe_palm 手掌从左到右，中心点(540,960)，0.45s
```

## 四、不要学歪

- 不要把拆出来的色板直接照抄进代码。先对照 `风格配方/` 找最近的一套，然后用脚本给的色值微调。因为参考视频的压缩、压缩、白平衡会偏色，真实沙画的色比视频里暖。
- 不要把「转场类型.txt」里的 0.40s 当成真理。复杂的飘散/流动要加 0.1–0.15s，不然观众还没看明白转场就结束了。
- 不要逐像素对齐关键帧。目标是「同样的机制做出同样的观感」，不是「同一帧像素一样」。
